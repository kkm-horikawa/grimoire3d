# Grimoire3D 0.3.0の計画

2026-11-20、通常の引用・残りの記法・リストの画面案と章順の方針を本人が承認。ゴールを設定し、実装から0.3.0のリリース・公開確認まで進める。

## ゴールに設定する到達点

書き手が既存の階層化されたMarkdownを本にし、YAMLで章順を指定できる。引用と一般的な記法が魔導書の紙面で読め、READMEとGrimoire3Dで公開する公式ドキュメントから使い方を確認できる。検査・実画面・PRを確認し、0.3.0としてリリースする。npmの公開版とGitHubのリリース、GitHub Pagesの公式ドキュメントを実際に開いて確認する。

## 実装する範囲

- 各フォルダの `index.md` のYAMLに `chapters` を書き、そのフォルダ内のMarkdownとサブフォルダの順番を指定する。
- 指定した項目に続き、未指定の項目は既存のファイル名順で取り込む。存在しない項目と重複は書き手へエラーを返す。
- 承認済みの通常引用を、細い金色の左罫線と余白で表示する。
- 統一画面案に沿ってチェックリスト、水平線、折りたたみ、数式、用語定義リスト、コードの色分け、脚注を表示する。
- 通常の箇条書きと番号付きリストも紙面に合う配色・余白に整える。入れ子、長文の折り返し、2桁の番号、途中の番号から始まるリストを確認する。
- 長文、入れ子、狭い画面、キーボード操作、静的HTMLとJavaScript有効の読書画面を確認する。

## READMEと公式ドキュメントへの追記

短い例と必要な説明で、次を伝える。

- `docs` 直下のフォルダが1冊の本になり、その中のMarkdownが章になる。
- `docs` 直下に置いたMarkdownは、まとめて別の1冊になる。
- 本の中のサブフォルダは同じ本に含まれ、各フォルダの `index.md` はそのグループの導入になる。
- 7冊以上で本の検索欄が表示される。カテゴリーまたは公開日が設定されている場合も検索欄が表示される。
- `chapters` の指定例と、省略時の順番、未指定ファイルを取り込む規則を示す。
- `index.md` の `title`・`description`・`socialImage`・`noindex`・表紙・カテゴリー・公開日・章順のYAML例を示す。
- サイト全体の `siteUrl`・言語・著者は `grimoire.yml` に置く。公開URLの指定によりcanonical URLとサイトマップを生成することを短く伝える。
- 残りの記法は、記述例と実際の表示を対応させる。

READMEは導入と構成例を短く示し、詳細な記法・設定例は公式ドキュメントへリンクする。両方の説明と公開版の動作が一致していることを確認する。
