Getting Started

Grimoire3D turns Markdown files into books you can open and flip through in a browser. This library was built with the same CLI.

Start with your first book. Then learn how to organize a library or publish it.

If you are embedding a book in an existing app, see BookViewer in React.

Your first book

Install the CLI

Use Node.js 22 or later. The current npm release predates the CLI. Build and pack a checkout that includes it.

npm ci
npm run build
npm pack

Install the resulting archive from the project where you want to write your book. Run npm init -y first if the project has no package.json.

npm install -D /path/to/grimoire3d-0.0.0.tgz
