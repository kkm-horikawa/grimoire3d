# v1.5

This release adds page breaks for longer chapters and makes sections easier to share.

## New features

Every Markdown file forms a chapter. Start a new section with a level-two heading to give it its own page.

### Keeping small topics together

Use level-three headings for details that belong on the same page.

### Text and tables

**New:** section links can be shared. *Tip:* copy the URL from the reader. The old ~~file-only links~~ limitation is gone.

| Feature | Markdown |
| --- | --- |
| Emphasis | `**bold**` or `*italic*` |
| Table | Pipe-separated columns |

## Migration

Keep your existing Markdown file names. Share a section by copying its URL from the reader.

### Existing links

Chapter links still open the start of the file. Links to a heading open the paper where it appears.
