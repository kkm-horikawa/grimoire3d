# Getting Started

Grimoire3D turns Markdown files into books you can open and flip through in a browser. This library was built with the same CLI.

Start with [your first book](./first-book.md). Then learn [how to organize a library](../writing/index.md) or [publish it](../publishing/index.md).

If you are embedding a book in an existing app, see [BookViewer in React](./react.md).
