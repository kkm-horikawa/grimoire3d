# Getting Started

Run `npx grimoire3d serve` from your project directory to open your existing Markdown as books. Grimoire3D looks for `docs/` directly under that directory by default. Existing Markdown works without a scaffold. Use the [configuration guide](../publishing/metadata.md) to customize the library as needed.

Start with [your first book](./first-book.md). Then learn [how to organize a library](../writing/index.md) or [publish it](../publishing/index.md).

If you are embedding a book in an existing app, see [BookViewer in React](./react.md).
